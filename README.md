# Olson Pro Wash — Website

Premium marketing site for **Olson Pro Wash** (Olson Landscaping &amp; Pro Wash LLC),
a pressure washing &amp; landscaping company serving Northwest Wisconsin.

Built with **Astro 4** + **Tailwind CSS**. Vanilla JS for all interactions — no React/Vue.

## Quick start

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static output in ./dist
npm run preview  # preview the production build
```

## Project structure

```
src/
├── components/        Reusable UI (Header, Footer, Hero, sliders, carousel, forms…)
├── content/
│   ├── config.ts      Blog content-collection schema
│   └── blog/          Markdown blog posts (SEO content)
├── data/
│   ├── site.ts        NAP / business info — EDIT THIS FIRST
│   ├── services.ts    Service catalog
│   └── testimonials.ts
├── layouts/
│   └── BaseLayout.astro   <head>, SEO, header/footer shell
├── pages/             Routes (index, services, about, gallery, contact, blog/…)
└── styles/global.css  Design tokens + base layer
public/
├── images/            SVG placeholders — swap for real photography
├── robots.txt
└── favicon.svg
```

## Things to customize before launch

| What | Where |
| ---- | ----- |
| Phone, email, address, hours, social links | `src/data/site.ts` |
| Production domain | `astro.config.mjs` (`site:`) and `src/data/site.ts` |
| Google Business Profile link | `src/data/site.ts` (`googleBusinessUrl`) |
| **HouseCall Pro booking widget** | search for `HOUSECALL PRO` in `src/components/HousecallProWidget.astro` — paste embed there |
| Real photos (hero, gallery, before/after, team, blog heroes) | `public/images/` |
| Open Graph share image | `public/images/og-default.svg` → replace with a 1200×630 PNG/JPG |

The phone number `(715) 555-0100` and domain `olsonprowash.com` are placeholders.

## Deployment (Netlify)

`netlify.toml` is preconfigured:

- Build command: `npm run build`
- Publish directory: `dist`
- Node 20, security + caching headers, pretty-URL redirects

Connect the repo in Netlify and deploy — no extra settings needed. Update the
`site` URL in `astro.config.mjs` so the sitemap and canonical URLs are correct.

## SEO

- Per-page `<title>`, meta description, canonical URL via `<BaseLayout>`
- Open Graph + Twitter card tags
- `sitemap-index.xml` auto-generated by `@astrojs/sitemap`
- `public/robots.txt` points crawlers at the sitemap
- `LocalBusiness` JSON-LD on the homepage; `BlogPosting` JSON-LD on posts
- RSS feed at `/rss.xml`
